# VoidTech on Render
1. Push this folder to a GitHub repo.
2. Render dashboard > New > Static Site > pick the repo.
3. Build command: leave empty. Publish directory: `.`
4. Deploy. Your site is live at https://<name>.onrender.com
Edit the content block at the top of the <script> in index.html (WhatsApp number, socials, titles, prices).
